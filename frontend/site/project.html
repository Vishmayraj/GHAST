A student project, built in the open.

What it is.

GHAST watches vessel position reports and flags the ones that do not fit how that vessel should be moving. It then investigates the flag, writes down what it found, and hands the incident to a person.

It is a three-semester build at GTU, written by one engineering student across semesters 5 to 7.

Where it stands.

Position data is collected and stored, a detector flags unusual reports, and an investigation agent turns a flag into a hypothesis with evidence. The analyst console, jamming areas, fleet-wide checks and measured accuracy are the work still ahead.

The pages on this site that look like product output use sample data and say so. The repository is the real state of the project at any time.
