# backend/models/

- `migrations/` - numbered SQL files (`NNNN_description.sql`), the source of truth for the schema. Applied by `python scripts/migrate.py up` and by ingestion on start.
- `schema.sql` - generated by `python scripts/migrate.py snapshot`. Do not edit it by hand; a test fails if it drifts from the migrations.
- `api_role.sql` - manual script that creates the read-only API database role.

Tables: `vessel_position` (hypertable), `vessel_static`, `incidents`, `jamming_zones`, `threshold_config`, `scoring_stats`, `schema_migrations`. See `docs/data-pipeline.md` for columns.
